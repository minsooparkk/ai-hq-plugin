# 한국어 낱말

> **Version**: 1.0.0

한국어로 쓸 때 피하는 낱말을 모았다. 쓰지 않는 말, 영어 동사를 그대로 옮긴 말, AI 글의 표시로 자주 꼽히는 낱말과 굳은 서술 틀이다. 대화, 문서, 기록, 커밋 글, 코드 주석 어디에나 적용하고, 몸에 밴 글버릇보다 이 규칙이 먼저다. 문장 틀은 rules/09-한국어-문장.md에 있다.

## Core Rules

### 1. 적용 범위 - 은유로 붙일 때만 잡는다

- 2번의 말은 뜻과 상관없이 쓰지 않는다.
- 4번부터 7번까지는 눈에 보이지 않는 대상을 빗대어 말할 때만 걸린다. 말 그대로의 뜻이거나 그 분야에서 정해 쓰는 용어면 걸리지 않는다. 예: 그래프의 가로축, 옷감의 결, 전기 회로의 경로, 고속도로 갈래길, 문서 편집기의 레이어.
- 걸린 낱말을 다른 비유로 갈음하지 않는다. 실제로 가리키는 것이나 실제로 한 일을 쓴다.

### 2. `박다`, 몸 동작 은유, 소리 흉내 말 - 쓰지 않는다

어떻게 활용했든, 어떤 글이든 쓰지 않는다.

- `박다` 무리: `박다`, `박는`, `박은`, `박혀`, `박아`, `박힌`, `박히`, `박았`, `박음`, `박아 두다`, `박아두다`, `박아둠으로써`, `박혀 있다`, `처박다`, `처박힌`, `못박다`, `때려박다`, `우겨박다`, `우겨넣다`
- 몸 동작 은유: `쑤셔 넣다`, `꽂다`, `때려 넣다`, `갖다 붙이다`, `처넣다`
- 소리와 모양 흉내 말: `쾅`, `탁`, `철컥`, `뚝딱`, `착`

그 자리에는 실제로 한 일을 정확히 가리키는 동사를 쓴다. 저장하다, 기입하다, 등록하다, 고정하다 같은 말이다.

| 쓰지 않는 말 | 바꿔 쓴 말 |
|---|---|
| 회의 날짜를 달력에 박아 둔다 | 회의 날짜를 달력에 등록한다 |
| 비밀번호를 설정 파일에 박는다 | 비밀번호를 설정 파일에 저장한다 |
| 단가가 계약서에 박혀 있다 | 단가가 계약서에 고정되어 있다 |
| 표에 숫자를 때려 넣는다 | 표에 숫자를 기입한다 |
| 보고서가 뚝딱 나왔다 | 보고서를 한 시간 만에 끝냈다 |

### 3. 영어 동사를 옮긴 말 - 우리말 동사로 바로 쓴다

have, make, take, give 같은 영어의 가벼운 동사를 글자대로 옮기면 어색하다. 우리말 동사나 형용사로 바로 쓰거나, '~이 ~하다' 꼴의 이중 주어 문장으로 고친다.

| 걸리는 꼴 | 바꿔 쓴 예 |
|---|---|
| 경험을 가지고 있다, 경험을 보유하고 있다 | 매장을 운영해 본 경험이 있습니다. 또는 한 일로: 매장 두 곳을 3년 동안 운영했습니다 |
| 강점을 가지고 있다 | 손이 빠르다, 가격이 싸다 |
| 결정을 내리다, 결정을 하다 | 팀장이 결정했다 |
| 영향을 주다 | 날씨가 매출을 크게 좌우한다 |
| 회의를 가지다 | 오후에 회의를 했다 |

### 4. 가장 먼저 잡는 명사 - 0회

| 표현 | 바꿔 쓰는 법 | 예 |
|---|---|---|
| 축 | 같이 다룬다고 쓴다 | 비용을 한 축으로 본다 → 비용도 같이 따진다 |
| 결 | 비슷하다, 다르다. 무엇이 다른지 쓴다 | 두 안은 결이 다르다 → 두 안은 드는 돈이 다르다 |
| 갈래 | 둘로 나뉜다, 두 가지다 | 의견이 두 갈래다 → 의견이 둘로 나뉜다 |
| 자리 | 있다, 돌아온다 | 핵심 기능으로 자리한다 → 핵심 기능이다 |

### 5. 물리적 은유 명사 - 0회

레이어, 척추, 등뼈, 해자, 두께, 토대, 기반 위에 세우다, 천장, 문턱, 제자리, 그 지점, 밀도, 농도, 경로, 게이트.

비유를 빼고 실제로 무엇이 달라지는지 쓴다. 예: 성장의 토대를 마련했다 → 다음 달부터 직원 두 명을 더 쓸 수 있게 됐다.

### 6. 동사 - 문서당 각 1회 이하

| 동사 | 바꿔 쓰는 말 |
|---|---|
| ~로 본다, ~로 읽는다 | 판단한다, 분류한다. 또는 단언한다 |
| 붙는다 | 생긴다, 추가된다 |
| 넓히다, 좁히다 | 범위를 ~까지 늘리다, 줄이다 |
| 열다, 닫다, 굴리다, 묶다, 묶이다, 다투다 | 시작하다, 끝내다, 운영하다, 합치다, 포함하다, 경쟁하다 |
| 남는다, 갈린다 | 결과를 직접 쓴다. 나뉜다, 달라진다 |
| 걷어낸다, 덮는다 | 뺀다, 지운다, 가린다 |
| 민다, 간다 | 계속한다. 다음에 할 일을 쓴다 |
| 버티다, 살아남다 | 결과를 직접 쓴다 |
| 뒤집다 | 바꾸다, 반대로 하다 |
| 던지다 | 입력하다, 보내다, 묻다 |
| 깔다 | 설치하다 |
| 갈아끼우다 | 교체하다 |
| 녹이다, 튀다, 받다 | 해결하다, 두드러지다, 처리하다 |
| 들어갑니다, 나갑니다, 넘어갑니다(진행을 알리는 말) | 지운다 |

### 7. 굳은 서술 틀 - 문서당 각 1회 이하

`~역할을 합니다`, `~로 자리합니다`, `~에 자연스럽게 맞습니다`, `~가 잘 맞습니다`, `~가 딱 맞습니다`, `~을 보장하며`, `~을 반영하며`, `~쪽입니다`, `~쪽으로`, `~상황입니다`, `~하고자 합니다`, `~라고 봅니다`, `~지는 않았습니다`, `흐름 안에서`, `그 위에서`, `가능한 범위 안에서`, `하나만 가져간다면`, `다음 걸음`.
