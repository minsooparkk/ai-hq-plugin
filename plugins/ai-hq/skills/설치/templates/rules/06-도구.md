# 도구(스킬 색인)

> **Version**: 1.0.0

일을 할 때 어떤 스킬을 쓰는지 찾는 색인이다. 스킬은 이 비서 플러그인에 들어 있다.

## Core Rules

### 1. 스킬 문서 - 일을 하기 전에 먼저 읽는다

일하는 순서와 판단 기준은 스킬 문서에 있다. 그 일을 할 때 먼저 그 스킬을 불러 문서를 읽고 그대로 한다. 기억에 기대 짐작으로 하지 않는다.

### 2. 한 일 기록 - 기록 파일에 한 줄

한 일은 `.harness/기록/YYYY-MM-DD.md` 맨 아래에 한 줄로 덧붙인다. 모양은 rules/03-하는-일.md 5번에 있다. 스킬마다 남기는 줄의 예가 그 스킬 문서에 있다. 한 턴에 못 끝내 비서가 이어서 할 일은 할 일 목록에 제목 앞에 `[비서]` 를 붙여 남긴다(스킬 할일-정리).

### 3. 스킬 색인 - 무엇을 할 때 어느 스킬

| 무엇을 할 때 | 스킬 |
|---|---|
| 본부 폴더를 처음 만들 때 | 설치 |
| 규칙이나 권한을 고칠 때 | 규칙-손질 |
| 메일, 메신저, 캘린더에서 새로 온 것을 가져올 때 | 입력-가져오기 |
| 가져온 것을 사람이나 회사별로 정리할 때, "그 사람이랑 뭐가 오갔지" | 사람-정리 |
| 할 일 더하기, 끝내기, 미루기, 보기 | 할일-정리 |
| 일정 보기, 겹침 확인, 비는 시간 찾기, 일정 넣기와 고치기 | 일정-정리 |
| 아침에 오늘 할 일 정리, "오늘 뭐 있어" | 하루-브리핑 |
| 아침 브리핑과 저녁 요약 | 아침저녁-요약 |
| 메일 답장 초안 쓰기와 보내기 | 메일-답장 |
| 승인 글 쓰기, 결정 묶음 남기기, "지난번에 승인한 것 뭐였지" | 승인-기록 |
| 텔레그램, 디스코드, 슬랙, Claude 앱 연결 | 메신저-연결 |
| 브리핑, 요약, 가져오기를 정해진 때에 저절로 돌게 할 때 | 예약-만들기 |

### 4. 스킬에서 배운 것 - MEMORY.md에 적는다

플러그인의 스킬 문서는 고치지 않는다. 플러그인을 새 판으로 바꾸면 덮이기 때문이다. 스킬을 쓰다 배운 것은 `.harness/memory/MEMORY.md` 에 스킬 이름을 붙여 적고, 다음에 그 스킬을 쓸 때 함께 읽는다.
