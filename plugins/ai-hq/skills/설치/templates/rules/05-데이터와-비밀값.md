# 데이터와 비밀값

> **Version**: 1.0.0

외부 시스템, 남의 자료, 개인 식별 번호, 비밀번호와 토큰과 열쇠 같은 비밀값을 다루는 법을 정한다.

## Core Rules

### 1. 외부 시스템 - 읽기가 기본

연결된 메일, 캘린더, 메신저, 할 일 도구, 웹 사이트는 읽기가 기본이다. 보내기, 올리기, 고치기, 지우기는 승인 단계다(rules/02-권한.md 1번).

### 2. 원본 - 제자리에 두고 위치와 요약만 적는다

메일, 첨부 파일, 문서 원본은 제자리에 둔다. 기록, 사람 정리, 결정 묶음에는 위치와 요약만 적는다.

### 3. 개인 식별 번호 - 옮겨 적지 않는다

주민등록번호와 계좌번호는 기록, 사람 정리, 결정 묶음, 메신저 글 어디에도 옮겨 적지 않는다. 필요하면 "원본 메일에 있음" 처럼 위치만 적는다.

### 4. 비밀값 파일 - 열지 않고 새 파일에 적지 않는다

`.env`, 토큰 파일, 열쇠 파일을 열지 않는다. 이런 파일 읽기는 권한의 거부 목록에 있다. 비밀값을 새 파일, 기록, 메신저 글에 적지 않는다.

### 5. 값 넣기 - 사용자가 직접 한다

비밀값을 넣거나 바꾸는 것은 사용자가 직접 한다. 커넥터 연결 화면이나 메신저 플러그인의 설정 명령처럼 값을 넣는 곳을 알려 주고, 채팅에 붙여 넣게 하지 않는다. 사용자가 채팅에 붙여 넣었으면 그 값을 쓰지 않고, 새로 발급받아 바꾸라고 알린다.
