# RULES: 어떤 상황에 어떤 규칙을 읽나

시작할 때 이 표와 '늘 읽힘' 파일만 읽힌다(CLAUDE.md). 일을 시작하기 전에 아래 표에서 지금 상황에 맞는 줄을 찾아 그 파일을 읽고 그대로 한다. 여러 줄에 걸리면 모두 읽는다.

| 이런 상황이면 | 읽을 파일 |
|---|---|
| 늘 읽힘(시작할 때 이미 들어 있음): 자율적인 결정, 승인과 결정 기록, 소통, 메신저 인터페이스 | rules/00-자율적인-결정.md, 01-승인과-결정-기록.md, 07-소통.md, 08-메신저-인터페이스.md |
| 권한이 없어 막혔을 때, 권한을 열거나 바꿀 때 | rules/02-권한.md, 스킬 규칙-손질 |
| 요청을 받아 어떻게 할지 정할 때, 새 일을 스킬이나 예약으로 만들 때, 기록 폴더 어디에 무엇을 쓰나 | rules/03-하는-일.md |
| 하기 전에 되돌릴 길을 만들 때, 저장소를 고치기 전, 지우기 | rules/04-작업.md |
| 남의 자료, 외부 시스템, 개인 식별 번호, 비밀값을 다룰 때 | rules/05-데이터와-비밀값.md |
| 도구나 스킬을 고를 때 | rules/06-도구.md, 그 스킬 문서 |
| 한국어로 글을 쓸 때(메일, 보고서, 메신저 글, 문서, 긴 답) | rules/09-한국어-문장.md, rules/10-한국어-낱말.md, rules/11-문장부호.md |
| 사용자가 정한 것이 걸린 일, 새 결정을 적을 때 | `.harness/결정/결정기록.md` (새 결정은 맨 아래) |
| 사용자가 지난 승인이나 거부를 물을 때 | `.harness/결정/요청/`, rules/01-승인과-결정-기록.md 6번, 스킬 승인-기록 |
| 배운 것이나 실수를 적을 때 | `.harness/memory/MEMORY.md` |
| 한 일을 남길 때, 지난 일을 찾을 때 | `.harness/기록/YYYY-MM-DD.md` (모양은 rules/03-하는-일.md 5번) |
| 규칙, 색인, 권한을 고칠 때 | 스킬 규칙-손질 |

- 번호는 순서다. 00~06은 일하는 방식, 07~11은 형식(소통, 메신저, 한국어 글쓰기)이다.
- 규칙 파일 형식: 제목, `> **Version**: x.y.z`, 적용 범위 한 문단, `## Core Rules`, `### N. 주제 - 판정`, 본문 순서다. 예와 예외는 **Correct**, **Incorrect**, **Exceptions** 줄로 적는다.
- 규칙을 고치면 그 파일의 Version을 올린다. 글만 다듬으면 끝자리, 규칙을 더하거나 빼거나 바꾸면 가운데 자리, 틀을 다시 짜면 첫 자리.
- 규칙을 고치는 것은 비서가 하고 결정기록에 한 줄을 남긴다. 승인 대상과 거부 목록을 줄이는 것만 사용자 승인이다.
