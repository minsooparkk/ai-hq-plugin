# 설치

사용자가 고른 폴더에 비서 본부를 만든다. 규칙(CLAUDE.md, RULES.md, rules/), 권한(`.claude/settings.json`), 기록 폴더(`.harness/`)를 틀에서 채워 쓴다. 이미 있는 파일은 덮어쓰지 않는다.

틀은 이 스킬 폴더의 `templates/` 에 있다. 읽을 때는 `${CLAUDE_SKILL_DIR}/templates/파일` 로 읽는다.

## 1. 다섯 가지를 묻는다

먼저 한 줄로 알린다: "본부 폴더를 만들려고 다섯 가지를 하나씩 여쭤볼게요." 그 다음 한 번에 하나씩 묻는다. 고를 것이 정해진 물음은 고르는 창으로 묻고, 사용자가 답하기 전에는 다음 물음으로 넘어가지 않는다. 사용자가 "기본으로" 라고 하면 기본값을 쓴다.

| 순서 | 묻는 것 | 채울 자리 | 기본값 |
|---|---|---|---|
| 1 | 본부 폴더를 어디에 둘지 | (폴더 위치) | 문서 폴더 아래 `AI본부` |
| 2 | 비서를 무엇이라고 부를지 | `{{비서이름}}` | Jarvis |
| 3 | 비서가 사용자를 무엇이라고 부를지 | `{{호칭}}` | 대표님 |
| 4 | 어떤 일을 하는지 한두 문장 | `{{하는일}}` | 없음. 꼭 받는다 |
| 5 | 비서와 말을 주고받을 곳, 그리고 얼마나 맡길지 | `{{메신저}}`, `{{맡기는정도}}` | Claude 앱, 조심 |

묻는 말은 쉽게 쓴다.

- 첫째 물음: 문서 폴더 위치를 이 컴퓨터에 맞춰 보여 준다. 맥은 `/Users/<사용자>/Documents/AI본부`, 윈도우는 `C:\Users\<사용자>\Documents\AI본부` 모양이다. 사용자가 다른 곳을 말하면 그곳을 쓴다.
- 넷째 물음: "예: 작은 디자인 회사를 운영하고, 고객 메일과 견적 일정이 많아요" 처럼 예를 하나 보여 준다.
- 다섯째 물음은 두 번에 나눠 묻는다. 먼저 메신저(텔레그램, 디스코드, 슬랙, Claude 앱 가운데 하나). 다음에 맡기는 정도.
  - 조심: 본부 폴더 안 파일을 고칠 때도 매번 허락을 묻는다. 처음 쓰는 분께 맞다.
  - 맡김: 본부 폴더 안 파일 고치기는 묻지 않는다. 메일 보내기, 지우기 같은 되돌릴 수 없는 일은 두 경우 모두 똑같이 묻는다.

## 2. 이미 있는 것을 본다

폴더 위치를 정했으면 아래 '쓰는 파일' 표의 쓸 곳마다 파일이 이미 있는지 본다. 있는 파일은 쓰지 않는다. 다 본 뒤 한 번에 알린다: "이미 있는 파일 n개는 그대로 두었습니다: 이름, 이름." 사용자가 바꿔 달라고 하면 그 파일을 `.harness/휴지통/YYYY-MM-DD/` 로 옮긴 뒤 새로 쓴다.

`.claude/settings.json` 이 이미 있으면 그 파일도 고치지 않는다. 대신 4절에서 더할 규칙 목록을 보여 주고, 사용자가 "넣어줘" 라고 하면 그 파일의 목록 맨 끝에 더한다. 이미 있는 규칙은 지우지 않는다.

## 3. 쓰는 파일

틀을 읽고, 채울 자리를 사용자의 답으로 바꾼 뒤, 쓸 곳에 쓴다.

| 틀(`${CLAUDE_SKILL_DIR}/templates/` 아래) | 쓸 곳(본부 폴더 아래) |
|---|---|
| `CLAUDE.md` | `CLAUDE.md` |
| `RULES.md` | `RULES.md` |
| `rules/` 의 열두 파일(00부터 11까지) | `rules/` 같은 이름 |
| `settings-조심.json` 또는 `settings-맡김.json` | `.claude/settings.json` |
| `harness/memory/MEMORY.md` | `.harness/memory/MEMORY.md` |
| `harness/결정/결정기록.md` | `.harness/결정/결정기록.md` |
| `harness/결정/요청/안내.md` | `.harness/결정/요청/안내.md` |
| `harness/기록/안내.md` | `.harness/기록/안내.md` |
| `harness/입력/안내.md` | `.harness/입력/안내.md` |
| `harness/사람/안내.md` | `.harness/사람/안내.md` |
| `harness/할일.md` | `.harness/할일.md` |
| `harness/휴지통/안내.md` | `.harness/휴지통/안내.md` |

- 틀 폴더 이름은 `harness` 이고 쓸 곳은 점이 붙은 `.harness` 이다.
- 권한 틀은 맡기는 정도가 '조심'이면 `settings-조심.json`, '맡김'이면 `settings-맡김.json` 을 쓴다.
- 채울 자리는 `{{비서이름}}`, `{{호칭}}`, `{{하는일}}`, `{{메신저}}`, `{{맡기는정도}}` 다섯이다. 사용자의 답을 글자 그대로 넣는다.
- 바꾼 뒤 자리 바로 뒤에 붙은 조사가 받침과 맞는지 보고 고친다. 예: 이름이 '민준'이면 '민준는'을 '민준은'으로.
- 파일은 글 쓰는 도구(Write)로 쓴다. 폴더가 없어서 쓰지 못하면 폴더를 먼저 만든다. 맥은 `mkdir -p "폴더"`, 윈도우 PowerShell은 `New-Item -ItemType Directory -Force -Path "폴더"`.
- 본부 폴더가 지금 Claude Code를 연 폴더 밖이면 쓸 때마다 허락을 물을 수 있다. 사용자에게 "파일을 쓸 때 허락 창이 뜨면 허용을 눌러 주세요" 라고 먼저 말한다.

## 4. 커넥터의 보내기 도구를 묻기 목록에 넣는다

지금 이 대화에서 쓸 수 있는 도구 가운데 이름이 `mcp__` 로 시작하는 것을 모두 본다. 그 가운데 밖으로 나가거나 되돌릴 수 없는 일을 하는 도구를 고른다. 이름에 이런 뜻이 들어 있으면 고른다: 보내기(send), 답장(reply), 전달(forward), 올리기(post, publish, upload), 만들기(create), 고치기(update, edit, modify), 지우기(delete, remove, trash), 옮기기(move), 나누기(share), 초대(invite), 결제(pay).

- 고른 도구의 전체 이름을 권한 파일의 `ask` 목록 맨 끝에 하나씩 더한다. 예: `mcp__claude_ai_Gmail__send_message`.
- 이름 뒤에 괄호를 붙이지 않는다. 괄호가 붙은 `mcp__` 규칙은 Claude Code가 읽지 않고 건너뛴다.
- 읽기만 하는 도구(찾기, 목록, 읽기, 가져오기)는 넣지 않는다.
- 애매한 도구는 넣는다. 넣어서 생기는 일은 허락을 한 번 더 묻는 것뿐이다.
- 연결된 커넥터가 하나도 없으면 넣지 않고, 끝에 알릴 때 "커넥터를 연결하면 스킬 규칙-손질로 보내기 도구를 묻기 목록에 넣으세요" 라고 한 줄 덧붙인다.

## 5. 다시 읽어 확인한다

- 쓴 파일마다 다시 읽어 `{{` 가 남지 않았는지 본다. 남았으면 채운다.
- `.claude/settings.json` 을 다시 읽어 괄호와 쉼표가 맞는지 본다. 이 파일에는 주석과 마지막 쉼표를 넣을 수 없다.
- CLAUDE.md 맨 위의 여섯 줄이 가리키는 파일이 모두 있는지 본다.

## 6. 기록을 남긴다

- `.harness/기록/YYYY-MM-DD.md` 에 한 줄: `- HH:MM · 비서 이름 · 설치 · 파일 n개 씀, n개는 이미 있어 그대로 둠, 묻기 목록에 커넥터 도구 n개 · 본부 폴더 위치`
- `.harness/결정/결정기록.md` 의 '결정' 아래에 사용자가 정한 다섯 가지를 한 줄씩 적는다. 예: `- YYYY-MM-DD 비서 이름을 Jarvis로 정함. 사용자가 한 말: "기본으로". 걸리는 곳: CLAUDE.md.`

## 7. 끝나면 알린다

결과부터 짧게 쓴다. 몇 개를 썼고 무엇을 그대로 뒀는지, 묻기 목록에 넣은 커넥터 도구가 무엇인지. 그 다음 먼저 할 일 하나와 이어서 할 일 셋을 알린다.

먼저 할 일: Claude Code를 본부 폴더에서 새로 연다. 터미널이면 본부 폴더로 옮겨 가서 `claude` 를 실행한다. 이 폴더에서 처음 열면 "이 폴더를 믿겠습니까" 하는 창이 뜬다. 허락해야 허용 목록이 적용된다. 규칙과 권한은 본부 폴더에서 연 Claude Code 에서만 읽힌다.

이어서 할 일:

1. 메신저 연결: "메신저 연결해줘" 라고 말하면 스킬 메신저-연결이 순서대로 안내한다. Claude 앱만 쓰면 하지 않아도 된다.
2. 예약 만들기: "아침 브리핑 예약해줘" 라고 말하면 스킬 예약-만들기가 안내한다.
3. 첫 일 시켜 보기: "새로 온 메일 가져와줘", "오늘 할 일 정리해줘" 처럼 말해 본다.

## 멈출 때

- 1절의 넷째 물음(하는 일)에 답을 받지 못하면 파일을 쓰지 않고 기다린다.
- 사용자가 고른 폴더가 시스템 폴더(맥의 `/System`, 윈도우의 `C:\Windows` 같은 곳)면 쓰지 않고 다른 곳을 고르게 한다.
- 파일을 쓰다가 거절되면 다른 길로 쓰지 않는다. 어느 파일에서 멈췄는지 알리고, 사용자가 허락하면 그 파일부터 다시 쓴다.
